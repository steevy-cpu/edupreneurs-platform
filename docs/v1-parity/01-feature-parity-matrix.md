# V1 feature-parity matrix: live web prototype → mobile

**Date:** 2026-11-26. **Status:** analysis for owner decisions. Nothing here was merged, deployed, imported or published.

## How this was established (and its limits)

* **Prototype:** read-only inspection of the connected Lovable project source (routes, components, migrations, edge functions). **The prototype was not run, and its database was not queried**: no student record, message or payment detail was read. "Existing web behavior" therefore means *present in source*. Whether a feature works for students today was **not** verified.
* **Rebuild:** git refs and pull requests of `steevy-cpu/edupreneurs-platform` on `main` at `1094eb0`. Test figures are quoted from the repository's own reports.
* The earlier audit `docs/architecture/platform-00/` was used as a secondary source and is marked where relied upon.

**Status vocabulary:** **Merged** (on `main`) · **Unmerged** (open draft PR) · **Designed** (documents only) · **None** (not implemented) · **Approval** (needs a product or legal decision before work is meaningful).

**Priority:** P0 = v1 cannot ship without it · P1 = required for v1 parity, can follow P0 · P2 = present in prototype, not in the v1 list, needs an owner decision · V2 = deferred by the owner.

## Product differences that must not pass unnoticed

1. **Social-00 is a noticeboard, not the social network students have.** No feed, follows, DMs or groups. Shipping it as "community" would be a visible reduction (`05-social-parity-gap.md`).
2. **The prototype's Jude is a French navigation helper**; the rebuild's Jude is a lesson-grounded tutor. Better pedagogically, but different, and not yet live.
3. **Quizzes** change from per-student AI generation to fixed reviewed sets.
4. **Exams** change from client-scored (answer key on the device) to server-scored. Scores and Gold earned in the prototype are **not trustworthy as records**.
5. **Creole UI** is new on mobile; the prototype is French-only.
6. **Content approval:** the prototype auto-publishes AI-generated lessons; the rebuild requires human approval. Imported content cannot honestly be labelled "approved" until reviewed (**OD-2**).
